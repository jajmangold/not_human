QUALITY NOTES
Start with wording. Kokoro has no native SSML or emotion tags. Short, complete sentences, commas, semicolons, and deliberate line breaks are the reliable controls.
Clone cleanly. Use one speaker, little room noise, and a transcript-like reference. KokoClone is an optional Kanade conversion stage; it does not replace the baseline.
Use Gemma as a director. Ask for “quietly delighted” or “tired but kind,” then keep the original and directed takes side by side. The model can improve phrasing, not grant Kokoro a true emotion channel.
